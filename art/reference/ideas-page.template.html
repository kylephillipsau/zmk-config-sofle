Screen ideas

Each screen below is drawn pixel for pixel at the panel's real resolution, in the colours from your screen photo. Live numbers would use the same pixel digits, baked into the firmware. The panel is 1-bit, so there are no greys; the checkerboard textures are dithering.

Left screen

Status on top, always visible. Underneath is a module slot. Each module is built around minutes, not hours: the keyboard has no clock, but it can time things relative to when it woke up. You can keep one module, or switch between them with L2+M.

Top row
Both batteries as % and bars. The right half's level comes over the split link, which needs one setting turned on.
Bar
Current layer name (BASE / NAV / SYSTEM), so the left side matches the legend on the right
Slots
Bluetooth slots 1 to 5: filled = active, solid = connected, dashed = paired but away, plain = free
Badges
⌘ ⌥ ⌃ ⇧ light up while held, which helps with layer-plus-modifier chords. The last badge is caps lock, since the board has no caps light.

Session

CUSTOM CODE

The stats idea, scaled to how you actually use the keyboard. A session starts when the keyboard wakes and resets after it sleeps.

Shows
Time typing, keys pressed, accuracy (share of keys that weren't backspace), peak WPM, and keys per minute over the last 30 minutes
Extra
A lifetime key count can be saved to the keyboard's storage every few minutes, so it survives power-off

Focus timer

CUSTOM CODE

A Pomodoro timer on the keyboard: 25 minutes of work, then a 5-minute break, counted down on screen. Start and pause it with L2+T, without touching the computer.

Shows
Time left, progress bar, which round you're on, what comes next
Note
The screen redraws once a second only while the timer runs

Last keys

CUSTOM CODE

Echoes what the keyboard actually sent, newest at the top, modifiers included. It's a learning aid while you get used to the layers: it shows whether that chord came out as ⌘⇧4 or something else.

Shows
The last five keys or shortcuts
Privacy
It displays what you type, so I'd skip plain letters and show only shortcuts and special keys

What you have now

REFERENCE

Stock nice!view status: left battery only, an output icon, a typing-speed graph, five large slot circles and the layer name. Everything here carries over into the new status area, except the circles, which shrink into a single row.

Just for fun

Full-height modules for a terminal person. The status area shrinks to a one-line strip at the top (both batteries, layer, Bluetooth slot), so the module gets the rest of the screen. All of these run on the keyboard alone except the last one, which needs a small daemon on your machine.

$ uptime

CUSTOM CODE

The status screen as a shell session. The load averages are real: your typing rate, smoothed over 1, 5 and 15 minutes with the same exponential decay the Linux kernel uses for CPU load, where 1.00 = 60 WPM.

Also
acpi battery bars for both halves, who shows the Bluetooth slot, and fortune picks a new git, vim or shell one-liner each time the keyboard wakes
Power
Redraws every few seconds while you type, and stops when you stop
Fun and genuinely useful: my pick.

Tuxagotchi

CUSTOM CODE

A Tamagotchi-style Tux. Typing feeds him, fast typing makes him happy, and he naps when you stop. He levels up from your lifetime key count, which is saved to the keyboard's storage, so he grows over weeks.

Shows
Animated Tux (frames advance on key presses, so no idle animation drains the battery), fed / joy / xp meters
Effort
Medium. Most of it is drawing a handful of sprite frames.

$ evtest

CUSTOM CODE

An input inspector for your own keyboard, like running evtest against it. It shows exactly what the last key did: HID usage code, key position and matrix row/column, active layer, modifier byte in binary, the binding that fired, and an event log with timing.

Use
Handy when you start hacking on the keymap, or wonder why a chord didn't work
Privacy
It shows keys, so I'd make it a mode you switch on (L2+M), not the default

Game of Life

CUSTOM CODE

Conway's Life on a 22 × 38 grid. Every key press advances one generation, and each key drops new cells at the spot matching its position on the board, so your typing keeps the colony alive.

Effort
Small. The simulation is about 30 lines of C.
Power
One redraw per key press, nothing while idle

Snake

CUSTOM CODE

An actual playable game. L2+G switches to a game layer, where the joystick steers instead of moving the mouse. The high score is saved.

Effort
The biggest of the on-keyboard ideas: a game layer, joystick input and a game loop of about 8 frames a second
Power
Only uses extra power while you're playing

Host link

NEEDS A DAEMON

A small daemon on your computer pushes data to the screen: the time, your last shell command's exit status and duration (from a zsh/bash prompt hook), the current git branch, CI status from gh, unread mail, CPU and memory.

How
The seller's ZMK fork lets firmware modules define their own messages for the Studio connection. A Python daemon on your machine sends updates over that link.
Catch
The biggest project here, and simplest over USB. Bluetooth is possible with more work. It's the only way to get a clock or anything else from the computer.

Layer legend

LIVE

Shows your name at rest. While you hold a layer key, it turns into a cheat sheet for that layer. It's personal most of the time and useful exactly when you need it.

Shows
Right battery, link to left half, then per-layer key maps for L1 (nav, F-keys, mouse, RGB) and L2 (BT slots, clear, USB/BLE, flash, soft off)
Needs
The left half sends its active layer to the right half. Your ZMK fork already has a relay feature for this.
Battery
About the same as now: it only redraws when the layer changes

Dashboard

CUSTOM CODE

Everything at a glance on one screen: both batteries as big numbers, which Bluetooth slot you're on with a name you choose, and a caps-lock banner. The board has no caps-lock light, so that banner is the most useful part.

Shows
L and R battery %, active slot plus your own label (e.g. WORK, IPAD), caps lock, layer

Quick keys

ART ONLY

A permanent card for the shortcuts you use too rarely to remember: soft off is Q+S+Z held for 2 s, Bluetooth slots are on L2, flash mode is L2+C, and so on.

Shows
Eight shortcuts taken from your actual keymap
Needs
Swapping the image only. It goes stale if you remap keys in ZMK Studio.
Catch

Session stats

CUSTOM CODE

A typing tracker: keys typed this session, a 12-hour activity chart, time awake, top WPM, and a countdown to sleep.

Shows
Counters since the keyboard last powered on (it has no clock, so there's no "today")
Needs

What you have now

REFERENCE

Stock ZMK picks the balloon or the mountain at random on every boot. The battery and link icons along the top come with every option above unless that design replaces them.

Not possible

The keyboard only receives the caps, num and scroll lock lights from your computer. So none of these can be shown:

  • a clock, the date or the weather
  • notifications, now-playing or CPU stats (only with a helper app on the computer, which is a much bigger project)
  • the computer's actual name (use your own slot labels instead)

Also possible on the left

  • A countdown to auto-sleep (1 hour idle)
  • Your own names for Bluetooth slots, e.g. MAC or IPAD
  • An estimate of battery time left. The fork's battery-history module can track the drain rate, but it needs days of data to be meaningful.

Already done

  • The local Docker build works for both halves
  • The name is set to Kyles Sofle and confirmed inside the firmware
  • The right-screen layer legend is flashed and working
  • The joystick has a gentler acceleration curve, precision mode on L2, and live speed tuning in DYA Studio. The knob scrolls on L1.
